
# PixelRise Agency Login & Registration System

A modern and responsive authentication interface built using HTML5, CSS3, and JavaScript.

The project provides professional login and registration pages for a fictional digital agency called PixelRise Agency.

---

# About

PixelRise Agency Login & Registration System was developed as a front-end web development project to demonstrate authentication interface design, responsive layouts, form validation, and user experience principles.

The project simulates a real-world authentication system used by digital agencies, businesses, and web applications.

# Features

## Login Form

Users can:

- Enter email address
- Enter password
- Show/Hide password
- Remember Me option
- Navigate to registration page
- Navigate to forgot password page

---

## Registration Form

Users can:

- Create new accounts
- Enter personal information
- Validate required fields
- Confirm password
- Navigate back to login page

---

## Validation

The application validates:

- Empty fields
- Email format
- Password length
- Password confirmation
- Required information

Example:

```text
Invalid email address

Password must contain at least 8 characters

Passwords do not match
```
